Enterprise Migration

NPSP to Nonprofit Cloud Migration

A large social-services nonprofit needed to move off legacy NPSP onto Salesforce Nonprofit Cloud — 72,000+ records across multiple programs — without breaking the workflows staff depend on. As lead developer and solution architect I ran it from requirements through to production: record types, an Experience Cloud portal for partner agencies, sharing architecture, flow-based rollups, and the data migration underneath.

Traced a recurring automation fault to a single architectural root cause and fixed it without weakening a compliance lock. Closed a permission leak with targeted SOQL. Built multi-agency data isolation so each partner sees only its own cases while internal staff see all.

72,000+ records live in production, with staff workflows intact.
